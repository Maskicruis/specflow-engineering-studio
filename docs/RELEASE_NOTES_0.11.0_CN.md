# SpecFlow Engineering Studio v0.11.0

## Word 封面、目录与图片标准化

- 新增工程设计、技术报告两种标准封面预设，支持项目、文档名称、单位、编审人员、编号与日期；单位与编审信息可在本机记住。
- 识别有明确分隔的旧封面，以及手工 / 原生目录，展示段落范围与文字预览。核对并确认后才替换；识别不明确时保留内容，不强行删除正文。
- 使用可信宏生成原生 Word TOC 目录域，支持 1–4 级标题、页码与跳转链接。编辑后可在 Word 更新整个目录，最终 DOCX 不含宏。
- 正文独立嵌入图片放入无边框 1×1 单元格，真正单倍行距、自动行高、居中，超页图片按比例缩小。已有表格中的图片保留数据表结构。
- 目录与图片整理在原 V35.1 排版后执行；用户提供的原 VBA 文件保持原始字节与校验值。

## 怎么使用

1. 通过「工具工作台 → Word 格式标准化」或 `Ctrl+Alt+W` 打开独立窗口，选择文档。
2. 在「封面、目录与图片」选择所需功能，填写封面信息。只统一格式仍无需模型。
3. 勾选 VBA 授权，开始处理。启用封面或目录时，先在右侧核对识别范围并勾选确认，再继续排版。
4. 下载新 DOCX，在 Word 核对分页与题注。修改正文后右键目录 → 更新域 → 更新整个目录。

## 验证

- 111 项自动化测试通过，流式显示测试等待实际渲染，不再依赖固定延时。
- 使用本机 Microsoft Word 验证旧封面 / 手工目录替换、浮动与嵌入图片、数据表保留，以及新增标题后的无宏目录更新。
- 输出文档逐页核验分页和图片布局；安装版与便携版附 SHA-256 校验文件。

## 边界与安全

只处理副本，不覆盖原件；输出无宏 DOCX。复杂封面 / 扫描目录 / 不明确的分节范围不会自动删除。本版提供内置预设，不导入外部封面模板。原有页眉页脚保留；外部链接图片和组合绘图不拆解。已有数据表的多图单元格不自动重构。Word 与 VBA 项目访问仍需要由用户准备，软件不更改宏安全设置。

本项目安装包未做商业代码签名；Windows 可能提示未知发布者。更新器继续执行 SHA-256 校验。
