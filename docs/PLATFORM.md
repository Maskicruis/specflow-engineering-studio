# 平台设计说明（v0.1）

## 数据流

```text
PDF ──MinerU──▶ document.json(canonical v1.0)  ──┬─▶ view.json（界面兼容视图）
                       │  items[]: {page, order, type, text/html/asset, bbox{pdf,normalized}}
                       └─▶ 本地 BM25 索引（rag.js）

提问 ──▶ 检索TopK（带 文档/页/条文号/坐标） ──▶ 组装编号上下文 ──▶ LLM ──▶ 回答 + 引用[n]
                                                    │
                                     引用点击 ──▶ 打开原PDF该页 + bbox 高亮
```

## 引用可核查的意义

回答里的 [n] 不是模糊出处，而是**可定位块**：文档 + 页码 + 内容块 id + PDF 点坐标(bbox)。
点击即跳转并高亮，便于设计/科研人员**逐条核对原文**，避免 LLM 幻觉。

## 场景模板

| id | 用途 | 要点 |
| --- | --- | --- |
| design | 工程设计规范查证 | 给结论+数值+依据条文；资料不足要说明 |
| research | 科研文献综述 | 结构化归纳、指出分歧与空白 |
| general | 通用问答 | 只依据片段作答并标注 [n] |
