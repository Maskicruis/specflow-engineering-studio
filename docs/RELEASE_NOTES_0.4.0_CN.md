# SpecFlow Engineering Studio v0.4.0

> 本版重点修复 PDF 阅读、引用跳转与问答能力边界，并继续作为独立工程项目发布。

## 阅读器与高亮

- PDF 阅读器在桌面窗口中从原生标题栏下方开始显示，标题、状态和关闭按钮不再被遮挡；
- 工具栏新增“适合页面”和第二个关闭入口，打开时会根据可用宽高完整显示当前页；
- 修复“先加载、再跳页”造成的并发渲染竞态，引用定位改为一次加载目标页；
- 引用同时保留 PDF 点坐标和左上原点归一化坐标，阅读器优先按 PDF.js 读取到的真实页面尺寸换算，从而稳定显示黄色高亮；
- 高亮后自动把命中区域滚动到阅读区中心，并显示“已高亮”状态。

## 引用格式

- 模型回答中的 `[1]`、`[2]` 等编号现在是可点击超链接，紧跟在对应事实或结论后；
- 每条回答末尾始终追加“原文链接”，同时保留下方完整证据卡片；
- 点击任一行内引用、末尾链接或证据卡片，都进入同一原文核查流程；
- 回答支持基础 Markdown，不再把 `**粗体**` 原样显示给用户。

## 完整大模型对话 + RAG

- 工程助手改为多轮对话界面，最近对话上下文会随下一轮发送；
- 新增三种可配置知识来源：
  - **智能问答**：优先使用资料库 RAG；无相关资料时仍调用通用模型；
  - **仅资料库**：严格依据检索片段，无命中时不使用常识补齐；
  - **通用对话**：跳过资料检索，像常规大语言模型客户端一样回答；
- 增加“新对话”入口，不影响文档数据库与 MinerU 解析工作流；
- 未配置 LLM 时继续保留本地 BM25 检索与原文核查，不伪装成生成式回答。

## 标准接口

- `/api/v1/ask` 与 SSE 接口新增 `retrievalMode`、`history`、`grounding`；
- 引用 Schema 新增 `bboxNormalized`，并同步写入 `locate`；
- 能力发现新增 `inline-citation-links`、`multi-turn-chat` 与 `general-llm-fallback`；
- 保持 v1 响应封装和原有接口兼容。

## 验证与升级

- 40 项自动化测试全部通过；
- 使用实际《电化学储能电站设计标准》PDF 完成桌面端页面适配、关闭按钮和高亮可见性验证；
- v0.4.0 为独立工程的新 Release，不覆盖旧知识库项目；已安装 v0.3.0 的用户可通过客户端更新或 Setup 覆盖升级，资料库不会被主动删除。
