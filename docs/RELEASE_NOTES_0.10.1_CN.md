# SpecFlow Engineering Studio v0.10.1

## Word 格式标准化更容易使用

- 新增四步向导：选择文档 → 准备与授权 → 处理或审核 → 下载副本。
- 打开工具自动检查 Microsoft Word、VBA 访问与模型配置，环境状态在顶部直接显示。
- 默认「只统一格式（推荐）」不调用模型。界面明确提示还缺什么；准备完成才允许开始，不自动勾选任何授权。
- 新增「使用说明」：首次使用、Word 权限、模型配置、建议审核、下载结果均有说明。
- 压缩文件选择区，常驻开始操作区，取消原来的大面积空白介绍。
- 结构审查提供建议计数、文字修订独立授权，以及没有建议时继续全文排版的操作。
- 错误原因在结果区完整显示，并给出重试办法；任务结束后可处理另一份文档。上传新文件时重新确认授权。
- 用户提供的 V35.1 VBA 原文件保持不变并校验 SHA-256；输出不含宏的 DOCX 和处理报告，不覆盖原件。

### 最简单的使用方式

1. 在「工具工作台 → 工程文档 → Word 格式标准化」打开工具，或按 `Ctrl+Alt+W`。
2. 点击「选择文件」，保持「只统一格式（推荐）」。
3. 环境可用后，勾选「允许执行随附 VBA」，点击「开始统一格式」。
4. 完成后点击「下载标准化 DOCX」，在 Word 中核对编号、题注、目录、分页与工程数据。

需要模型检查标题层级时，改选「先审查结构，再统一格式」，配置模型并同意文本发送。模型只提出建议，您审核后才应用；文字建议默认不采用。

## 实时流式问答

- 上游模型流式请求 → SSE 逐块转发 → 前端实时 Markdown 与引用渲染。
- 接口支持时单独显示思考增量，支持停止、超时及断线提示，不将未完成回答保存为完整对话。
- 图片粘贴、RAG、最近对话、Harness 连接及原文定位继续兼容。无需修改 DeepSeek Harness Studio。

## 环境与升级

Word 工具需要 Windows 与 Microsoft Word，并由用户在 Word 中启用「信任对 VBA 工程对象模型的访问」。不需要启用所有宏，SpecFlow 不更改全局安全设置。只有模型辅助模式需要模型配置；PDF 解析仍需独立安装 MinerU。

关闭旧版后运行安装包覆盖安装；配置、资料库与对话保留。提供安装版、便携版和 SHA-256 校验文件。

安装包目前未进行代码签名，Windows 可能显示未知发布者提示。请从本仓库 Release 下载并核对 SHA-256；应用内更新也会检查校验值。
