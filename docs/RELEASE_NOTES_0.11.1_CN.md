# SpecFlow Engineering Studio v0.11.1

## 更清晰的对话与实时反馈

- 参考 DeepSeek / Codex 的对话布局，移除回复大卡片及重复星标，改为舒适的阅读列、柔和用户气泡和轻量模型状态。
- 标题、编号 / 嵌套列表、引用块、代码块与表格采用实际结构排版，不再全部挤在一个段落中；正文默认常规字重，仅强调内容加粗。
- 新消息淡入、等待圆点和生成状态呼吸动画。动画不拖慢真实流式转发，恢复历史不会逐条播放；系统要求减少动态效果时关闭相关动画。
- 句末引文仍为可点击链接，文后保留原文链接；原文片段卡片默认折叠，按需展开。
- 新增复制回复（含参考来源）和复制代码，点击后显示完成反馈。
- 生成时可以向上阅读历史内容，不强制跳回底部；点击「回到最新」可恢复实时跟随。
- 所有新增对话颜色使用共享主题变量，适配深色、浅色及较窄窗口。

## 使用

进入「知识库问答」即可使用新界面，无需迁移资料或重新解析文件。已有对话也采用相同排版。展开「查看原文片段」可查看引用摘录，点击正文中的引用编号或文后「打开原文」继续使用原有定位、高亮功能。

本次不改变模型配置、会话存储格式、数据库分组或 Harness 接口。模型 HTML 按文本转义，仅支持安全的 HTTP / HTTPS 普通链接，不自动加载模型回答中的远程图片。

## 验证

- 119 项自动化测试通过。
- 隔离的 Electron 窗口验证真实 SSE 增量渲染、阅读位置、恢复跟随、行内引用点击、回复 / 代码复制、深浅主题及减少动态效果。
- 已检查深色、浅色、展开原文片段与 980 px 窄窗口截图；窄窗口标题栏不再折行。
- 安装包内新模块与源码逐项校验一致，独立 Node 运行时能够正确提供新的对话样式和脚本。
