# SpecFlow Engineering Studio v0.6.1

> Codex 式对话侧栏与可靠的应用内文件分组管理

## Codex 式对话工作区

- 左侧顶部新增一级“新对话”入口，点击后立即进入知识库问答并创建全新的上下文；也可使用 `Ctrl + N`。
- “最近对话”改为占满侧栏剩余高度的单行列表，不再放进狭窄的独立框中。
- 去除重复图标和次要元数据，标题更易浏览；完整轮数和更新时间保留在悬停提示中。
- 当前对话保持高亮，删除按钮只在悬停或键盘聚焦时出现，减少视觉噪声。

## 文件分组修复

- 修复 Electron 桌面窗口中点击“新建分组”可能完全没有反应的问题。
- 新建、重命名和删除分组全部改为应用内编辑器，不再依赖不可靠的浏览器 `prompt()` / `confirm()` 弹窗。
- 分组名称支持回车保存、Esc 取消，并提供空名称、重名或接口错误的就地提示。
- 后台定时刷新文档状态时会保留正在输入的分组名称，不会清空或抢走编辑状态。
- 删除分组仍只会把文档移到“未分组”，不会删除 PDF、解析结果或引用坐标。

## 验证

- 真实浏览器交互验证：新建分组编辑器可见、输入内容经过后台刷新仍保留、取消不写入数据、侧栏“新对话”可正确返回问答页。
- 自动化测试：52/52 通过。

## 安装说明

推荐下载 `SpecFlow-Engineering-Studio-Setup-0.6.1-x64.exe` 覆盖安装。也可使用 `SpecFlow-Engineering-Studio-Portable-0.6.1-x64.exe` 免安装运行。资料库、分组、对话、Harness 项目和设置均会保留。
