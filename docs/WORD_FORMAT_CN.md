# Word 格式标准化

从「工具工作台 → 工程文档 → Word 格式标准化」打开独立窗口，或按 `Ctrl+Alt+W`。顶部四步进度条和左侧「下一步」提示会引导操作，右上角「使用说明」可随时打开。

## 快速开始 只统一格式

1. 点击「选择文件」，或拖入 DOCX / DOC 文档，最大 50 MB。原文件不会被覆盖。
2. 保持默认「只统一格式（推荐）」。该模式不调用模型，也不需要 API Key。
3. 顶部显示「Word 排版环境可用」后，勾选「允许执行随附 VBA，仅处理这份文档的副本」。
4. 点击「开始统一格式」，右侧实时显示进度。没有满足条件时按钮禁用，左侧会说明原因。
5. 完成后点击右侧「下载标准化 DOCX」。需要排查时也可下载处理报告。
6. 在 Word 中检查工程数值、标题编号、图表题注、目录及分页。V35.1 不仅改变字体，也会按规则整理编号和题注域。
7. 点击「处理另一份文档」开始下一份。新文件需重新勾选授权。

## 可选模式 先审查结构 再统一格式

需要检查标题层级时才选择该模式：

1. 在主程序「设置 → 模型接口」配置 Base URL、模型名称及所需的 API Key。
2. 回到 Word 工具，点击「重新检测」。选择「先审查结构，再统一格式」。
3. 除 VBA 授权外，还需同意将提取的文档文本发送到配置的模型接口。检查要求可选，例如「检查章节层级，不修改工程数值或技术内容」。
4. 点击「先分析结构，生成审核建议」。此时只分析，不自动应用建议。
5. 在右侧逐项审核，调整目标层级或取消勾选。文字建议默认不采用；需要改文字时，勾选该项的「采用文字建议」，并另外勾选文字修订授权。
6. 点击「按审核结果统一格式」并确认。未采用的模型建议不应用，但 VBA 全文排版规则仍执行。没有结构建议也可以继续全文排版。
7. 下载 DOCX；模型文字修订保留 Word 修订痕迹，最终接受或拒绝仍由您决定。

模型最多审查前 1000 段 / 60000 字，建议计划最多 400 项。VBA 排版覆盖全文。禁止模型调整表格、图片、公式、域和已有修订的结构；模型不能产生可执行代码。结构审查不替代工程内容校审。

## 标准封面与可更新目录

在左侧「封面、目录与图片」设置：

1. 封面默认保留。改为「使用预设标准封面」，可选择工程设计封面或技术报告封面，填写项目名称、文档名称、单位、编审人员、编号及日期。点击「记住单位与编审信息」保存本机预设，不保存处理授权。
2. 勾选「生成可更新目录」，选择 1–4 级。目录根据 V35 的实际标题样式生成，包含页码与跳转链接，不使用模型编写静态条目。
3. 开始后先读取结构，在右侧显示旧封面 / 目录的段落范围和文字预览。核对后勾选范围确认，再点击「按审核结果统一格式」。纯 VBA 模式也需要这一步；不会自动替换。
4. 可靠识别的旧封面或手工 / 原生目录会替换。未识别封面时只插入新封面，保留原首页；目录有歧义或涉及不安全的分节边界时，取消任务并选择保留原目录。

“宏格式目录”在这里采用 **由宏生成的原生 Word TOC 域**。输出仍是无宏 DOCX，无需让收件人启用宏。修改标题或内容后，在 Word 右键目录 → 更新域 → 更新整个目录，或者选中目录按 F9。页码可能随编辑、字体或打印环境变化，需要重新更新。

封面预设使用普通可编辑的 Word 段落；保留原有分节页眉页脚，不引入公司标识或虚构单位信息。复杂封面、扫描封面、目录表格、签署页等不会被强行删除；该版本不导入外部 DOTX / DOCX 封面模板。

## 图片单元格标准化

默认启用，可在左侧关闭。正文中每张独立嵌入图片放入一个无边框 1×1 表格，图片段落居中，使用真正的单倍行距，自动行高，不裁剪、不拉伸。超出可用页面宽度 / 高度时按比例缩小；不会放大低分辨率图片。原题注保留在图片表格之外。

已有表格中的图片不拆散数据表、不嵌套新表格，只统一图片所在段落的行距和尺寸。因此，同一原单元格中有多张图片时，不自动重构该表格。正文浮动的普通嵌入图片转为行内图片；外部链接图片、组合图形、OLE、公式、页眉页脚和可识别封面中的图像保持原结构，并在处理报告列出保留对象计数。复杂图文混排仍需在 Word 核对。

## 首次环境准备

- 需要 Windows 10 / 11、Microsoft Word，并完成 Word 首次启动。WPS 或 Office 查看器不能代替 Word 自动化。
- Word → 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置，勾选「信任对 VBA 工程对象模型的访问」。无需选择「启用所有宏」。
- 关闭 Word 的设置对话框，回到工具点击「重新检测」。SpecFlow 不替您改变安全设置；组织策略可能禁止此功能，遇到限制请联系管理员。
- 打开工具时会自动检查一次。重新配置模型或 Word 权限后可手动再检测。纯排版模式不受「模型未配置」影响。

## 遇到问题

- **开始按钮灰色**：先看左侧「下一步」，会说明缺文件、VBA 授权、Word 权限、模型配置或文本发送授权中的哪一项。
- **等待审核**：操作按钮在右侧建议表下方，点击「按审核结果统一格式」，不是再次点击左侧开始。
- **模型失败**：检查主程序模型设置；仅需排版时点击「返回准备，重新处理」，切换到「只统一格式」，不会再次调用模型。
- **受保护或有密码的文档**：在 Word 中处理独立副本，解除保护后再选择该副本。
- **文档已有未解决的修订**：先在 Word 独立副本中审核修订。不要覆盖原件。
- **Word 卡住或超时**：检查首次启动、加载项或提示对话框。错误原因完整显示在右侧；可返回准备后重试。
- **找不到结果**：完成任务后从右侧下载，也可从「最近任务」恢复已完成结果。副本与报告保存在本机应用数据目录的 `word-format` 下。

## 非破坏式处理

只处理本机上传副本，不覆盖原文件，不修改已打开的用户文档或 Normal 模板。输入文件的宏禁用；不接受 DOCM。输出 DOCX 不包含宏，但中间 DOCM 与 VBA 验证备份保存在本机任务目录。

取消时请求在 VBA 阶段边界退出，卡住时仅终止经过 PID 与启动时间校验的专用 Word 实例，不批量结束用户 Word。

关闭工具窗口不会取消后台任务；重新打开可从「最近任务」恢复。服务重启会将未完成任务标记为中断，不将其作为成功结果。

## 外部调用

使用版本化 `/api/v1/word-format/*` 接口，见 [API 契约](API.md)。VBA 许可、模型文本发送许可、计划审核和文字修订许可必须由用户确认；调用方不能用文件内容或模型输出代替授权。
