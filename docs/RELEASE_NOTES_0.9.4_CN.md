# SpecFlow Engineering Studio v0.9.4

> 本次小版本更新品牌图标、CRRC 工程视觉语言、高分屏显示与完整主题切换，并保持既有知识库、问答和设计工具数据兼容。

## 简洁新能源图标

- 移除原有文档造型，改为简洁的轨道动势、风机与光伏线条组合；
- 使用蓝、红与新能源青色建立更清晰的工程品牌识别；
- 重新生成 Windows 16、24、32、48、64、128、256 像素图标帧，改善任务栏、快捷方式和安装程序中的清晰度；
- 主窗口、安装程序、卸载程序和应用内品牌标识统一使用新版图标。

## CRRC 工程界面与高分屏显示

- 在现有布局基础上增加轨道交通与新能源色彩语言，不改变用户熟悉的工作流程；
- 使用 Windows 可变字体栈、字体平滑和高分屏支持，提高正文、菜单与工具画布的显示质量；
- 标题栏、侧边栏、导航选中态和主要操作按钮采用统一品牌色；
- 道路排水坡度设计独立窗口同步使用新版视觉系统。

## 完整主题切换

- 将标题栏、设置抽屉、遮罩、PDF 阅读器、引用高亮和设计画布纳入语义化主题变量；
- 修复切换深色或浅色主题后部分区域仍保留旧颜色的问题；
- 独立设计工具窗口可读取并跟随主程序的主题设置；
- 应用启动时提前恢复主题，减少窗口首次显示时的颜色闪烁。

## 验证与兼容

- 80 项自动化测试全部通过；
- 已完成深色、浅色主界面及道路排水坡度工具窗口的截图检查；
- 安装包继续支持 Windows 10/11 x64、便携运行和客户端内更新；
- 文档数据库、工程项目、会话记录、Harness 连接器、MinerU 配置和设计工具数据无需迁移。
