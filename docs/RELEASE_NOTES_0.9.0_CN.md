# SpecFlow Engineering Studio v0.9.0

> 本次版本重做道路排水坡度网络设计，并新增规范网站动态监测。

## 规范动态监测

- 文档数据库新增“规范动态监测”，可登记多个公开规范发布网站；
- 支持每 6 小时、12 小时、每天或每周自动检查，也可手动全部检查；
- 首次检查建立基线，后续显示新增和移除的规范链接、最后检查时间、最后变化时间及错误记录；
- 定时任务随本机 SpecFlow 服务运行，服务重启后自动补查到期任务；
- 内置 SSRF 防护、每次重定向复核、20 秒超时、5 MB 响应限制和最多 3 个并发检查。

## 道路排水坡度网络设计

- 新增选择与框选，可一次移动或删除多个节点；
- 双击节点按上、下、左、右方向自动创建下一节点及排水连线；
- 双击坡段即可反转排水方向，连线以动态流点显示方向；系统启用“减少动态效果”时自动停用动画；
- 画布坐标和网格仅表达拓扑，所有计算只采用用户输入的实际距离；
- 节点主要编辑编号与已知标高，坡段编辑距离、设计坡度和规范最小/最大坡度；
- 从一个或多个控制标高沿网络双向传播计算，对多路径矛盾、固定标高冲突、逆坡、超出规范范围和未连通节点给出提示；
- 支持标高小数位配置、坡段结果表和包含计算结果的 JSON 导出。

流向动画为 SpecFlow 独立实现，设计思路参考 MIT 许可项目 [tt-a1i/archify](https://github.com/tt-a1i/archify) 的方向感知 trace-motion。

## 兼容与数据

- 自动迁移旧版坡度设计本地数据；旧数据缺少实际距离时采用当前默认距离，不再从画布几何长度推断；
- 文档、索引、分组、对话、工程项目、模型设置及 Harness 集成保持兼容；
- 新增 API：`/api/v1/spec-monitors` 及检查、更新、删除端点；
- 68 项自动化测试全部通过。
