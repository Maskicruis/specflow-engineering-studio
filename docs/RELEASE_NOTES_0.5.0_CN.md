# SpecFlow Engineering Studio v0.5.0

> 智能体工作区、项目记录、DeepSeek 余额与完整文后原文链接

## 本次重点

### DeepSeek Harness Agent 已集成

- 新增独立的“DeepSeek 智能体”页面，直接承载官方 DSH 工作区。
- Harness 自带类似 Codex 的左侧项目记录和会话记录，可继续既有工程上下文。
- “打开项目”可登记任意本地工程目录；默认工作区、端口和自动启动均可在界面配置。
- 安装包内置 DSH 0.1.0-rc.7、所需官方运行插件以及独立 Node.js 运行时，不再依赖系统 Node 环境。
- 自动安装受管理的 `specflow-knowledge-base` Skill，让 Agent 能调用本机知识库标准 API；遇到用户自建同名 Skill 时不会覆盖。

### DeepSeek API 余额

- 标题栏新增余额入口，沿用官方 DSH 的凭据文件。
- 支持点击刷新并展示币种与总余额。
- API Key 只在 Electron 主进程内读取和使用，不返回渲染页面、不写入日志和发布产物。

### 引用链接再次完善

- 保留回答正文中紧跟结论的 `[1]`、`[2]` 行内链接。
- 回答末尾新增清晰的参考来源列表，逐条显示文档名、页码、条文号和“打开原文 ↗”。
- 行内引用、文后链接和证据卡片使用同一定位数据；点击即可跳至 PDF 对应页并高亮命中区域。

### 原有能力保持不变

- “知识库问答”继续支持智能问答、仅资料库和通用对话，RAG 不会限制一般问题的回答能力。
- “文档数据库”继续提供 MinerU 解析、阅读顺序恢复、表格/图片保留、PDF 定位和高亮。
- 标准 `/api/v1` 接口、SSE、混合检索和客户端自更新全部保留。

## 稳定性与验证

- 修复 DSH 官方 peer dependency 不随主包自动安装导致的启动失败。
- 增加 DSH API 就绪重试，确保首次启动后默认项目能可靠进入项目记录。
- 安装更新前停止自带 Harness 进程，避免安装器覆盖文件时被占用。
- 自动化测试：46/46 通过；另完成真实 DSH 启动、项目登记和停止冒烟测试。

## 安装说明

推荐下载 `SpecFlow-Engineering-Studio-Setup-0.5.0-x64.exe`。也可使用免安装便携版。DeepSeek Harness 已包含在安装包中；MinerU 仍需单独安装并在 SpecFlow 设置中选择实际的 `mineru.exe`。
