# SpecFlow Engineering Studio v0.6.0

> 最近对话、文档分组与分组范围问答

## 最近对话

- 工作区左侧新增“最近对话”，布局和使用方式参考 Codex。
- 每条记录显示首个问题生成的标题、轮数和最近更新时间。
- 点击记录可恢复完整多轮问题、答案、正文引用、来源卡片以及原检索范围，并可直接继续追问。
- “新对话”会清空当前上下文并创建独立记录；历史记录可以单独删除，不影响引用文档。
- 旧版本按单次提问保存的记录可自动读取并升级为单轮会话。
- 标准问答接口支持 `conversationId`；外部 Agent 即使不重复传入 `history`，服务端也能恢复会话上下文。

## 文件分类与分组管理

- 文档数据库新增独立的分组栏，包含“全部文档”“未分组”和用户自建分组。
- 支持新建、重命名和删除分组；删除分组只将所属文档移回“未分组”，不会删除 PDF 或解析结果。
- 每份文档都可直接从列表中的下拉菜单调整分组。
- 导入 PDF 前可选择目标分组，解析完成后自动保留归属。
- 分组只保存轻量元数据，不移动实体文件，因此不会破坏 PDF 原文路径、引用链接或高亮坐标。

## 分组范围问答

- 问答输入框的范围菜单新增“文件分组”和“单个文档”两级选择。
- 可只依据指定专业、项目或自定义分组生成回答。
- 指定分组没有文档或没有命中时，不会错误地退回全库检索。
- `/api/v1/groups` 提供分组 CRUD；`PATCH /api/v1/documents/:id` 提供文档归组；`POST /api/v1/ask` 支持 `groupId`。

## 稳定性与兼容性

- 当前文档在首次启动新版本时自动归入“未分组”。
- 现有资料库、解析结果、Harness 项目、设置与历史记录均保留，无需重新解析 PDF。
- 自动化测试：52/52 通过。

## 安装说明

推荐下载 `SpecFlow-Engineering-Studio-Setup-0.6.0-x64.exe` 并覆盖安装。也可使用 `SpecFlow-Engineering-Studio-Portable-0.6.0-x64.exe` 免安装运行。
