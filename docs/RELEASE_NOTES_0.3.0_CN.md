# SpecFlow Engineering Studio v0.3.0

> 可更新桌面发行版：统一品牌图标、可靠覆盖安装和应用内 GitHub Release 更新。

## 本版重点

### 应用内软件更新

- 设置抽屉新增“软件更新”，显示当前版本、最新版本、状态和下载进度；
- 可配置“启动后自动检查”，也可随时手动检查；
- 下载任务单实例运行，避免重复点击并发写入同一文件；
- 安装包下载完成后强制校验 SHA-256，缺少或不匹配时拒绝安装；
- 点击“安装并重启”后打开标准 Windows 安装向导，支持覆盖升级。

### 统一 Windows 安装体验

- 安装版允许选择安装目录，按需申请权限；
- 创建桌面和开始菜单快捷方式，安装完成后可直接启动；
- 提供免安装 Portable 版本；
- 安装器、卸载器、可执行文件、快捷方式和标题栏使用同一套 SpecFlow 图标。

### 全新独立图标

新图标组合“工程文档、结构化数据库、原文定位节点”三层含义，并生成 16、24、32、48、64、128、256 像素专用 ICO 帧，保证 Windows 标题栏、任务栏和快捷方式清晰显示。

### 延续工程文档能力

- MinerU 解析真实阅读顺序，修复章节乱序和表格展示问题；
- 文档数据库独立页面，支持导入、搜索、队列和解析状态；
- BM25 / 混合检索、流式问答、会话历史和结构化导出；
- 引用一键跳回 PDF 原页并按坐标高亮，可核查表格和正文来源；
- 标准化 API、Schema 与能力发现接口，为 Agent/知识库平台集成预留。

## 升级说明

v0.3.0 是独立工程项目的新 Release，不覆盖旧知识库项目。若已安装 v0.2.0，可直接运行 v0.3.0 Setup 覆盖升级；用户资料库和应用数据不会被主动删除。

注意：MinerU 是独立解析引擎，不包含在本安装包中。安装后请在“设置”中选择实际的 `mineru.exe` 并点击“检测”。

## 验证结果

- 自动化测试：37/37 通过；
- 覆盖更新器、SHA-256 校验、Windows ICO 多尺寸帧、桌面桥接、解析顺序、表格、坐标、检索、问答与引用定位；
- 安装版和便携版由同一份 v0.3.0 源码构建。
