# SpecFlow Engineering Studio v0.6.2

> 文件分组交互重做与分类设置中心

## 文件分组完整修复

- “新建分组”改为居中的应用内对话框，自动聚焦名称输入框，不再挤在数据库左栏底部。
- 创建按钮显示明确的提交状态；空名称、重名和接口错误会保留窗口并就地提示。
- 用户分组的重命名与删除按钮始终可见，不再依赖鼠标悬停才能发现。
- 重命名和删除使用同一套应用内对话框；删除只移除分类，文档、PDF、解析结果和引用坐标都会保留。
- 支持 Enter 保存与 Esc 取消，后台文档状态刷新不会干扰输入。

## 设置中心布局优化

- 设置窗口由狭窄的单列长表单升级为宽版双栏布局。
- 左侧按“资料与解析”“模型接口”“Harness Agent”“软件更新”分类。
- 右侧一次只展示一个配置页面，并将路径、解析参数和操作按钮分成独立卡片。
- 设置窗口增加背景遮罩、固定标题区和一致的底部操作区域，避免与数据库内容混在一起。
- 用户最后访问的设置分类会保留；从解析引擎入口打开时会直接进入解析设置。

## 完整验证

- 在隔离数据目录中完成 UI 闭环：创建分组 → 重新读取 → 重命名 → 删除，全部成功。
- 设置页的解析/模型分类切换已通过真实界面验证。
- 自动化测试：52/52 通过。

## 安装说明

推荐下载 `SpecFlow-Engineering-Studio-Setup-0.6.2-x64.exe` 覆盖安装。也可使用 `SpecFlow-Engineering-Studio-Portable-0.6.2-x64.exe` 免安装运行。资料库、分组、历史对话、Harness 项目和设置均会保留。
