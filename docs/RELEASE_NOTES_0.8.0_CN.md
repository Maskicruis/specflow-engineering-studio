# SpecFlow Engineering Studio v0.8.0

## 工程助手与全过程提醒

- 新增独立“工程助手”分组和“设计助手”工作区；
- 输入项目名称并选择根目录后，一键创建标准阶段目录；
- 默认目录为 `00工作区间`、`01初步设计`、`02施工图设计`、`03提资资料`、`04收资资料`、`05规程规范`；
- 设置页可自定义目录模板，并可把新增目录同步到已有项目；
- 新增分阶段资料完整性检查清单，覆盖洪水位、勘察、外部接口、消防、道路排水、技术经济指标、审查意见闭环等内容；
- 检查项支持“待收集 / 已具备 / 不适用”、备注、自定义追加和项目完成率。

## 设计工具

- 新增可扩展“设计工具”工作区；
- 可配置并启动用户现有的多功能计算器，快捷键为 `Ctrl+Alt+C`；
- 新增道路排水坡度设计器，快捷键为 `Ctrl+Alt+R`；
- 支持 Visio 式节点布置、拖动、箭头连接、坡度设置、控制标高、箭头反向和坡段结果表；
- 沿排水箭头自动计算下游设计标高，可设置 0–6 位标高小数并导出 JSON；
- 外部计算器不被复制到仓库或安装包，避免对未知授权程序进行二次分发。

## DeepSeek 余额与安全

- 标题栏新增 DeepSeek API 余额显示与手动刷新；
- 复用当前用户 DeepSeek Harness 的凭据文件并调用 DeepSeek 官方余额接口；
- API Key 不会返回渲染页面、写入日志或进入 Release 产物；
- 保持与 DeepSeek Harness Studio 并行运行，不内置第二套 Harness Runtime。

## 标准接口与质量

- 新增工程工作区、项目创建、目录同步和检查清单的 v1 API；
- 修复未选择项目根目录时可能误用程序当前目录的边界；
- 修复道路标高输入必须失焦后才可计算的问题；
- 62 项自动化测试全部通过，并完成设计助手及道路坡度画布的实际界面验证。
