# SpecFlow Engineering Studio v0.9.5

> 支持直接粘贴图片、多模态对话，以及结合图片内容的规范检索。

- 在知识库问答输入框中按 `Ctrl+V` 即可粘贴截图；同时支持拖入图片和点击“＋”选择图片。
- 图片附件包含缩略图、移除、放大查看、添加进度和重试；可同时发送多张图片，也可仅发送图片。
- 保存图片会话记录，重新打开最近对话后可查看原图并继续追问。
- 对接 DeepSeek 当前图像协议，含图片的消息默认使用 `deepseek-flash`；其他 OpenAI 兼容服务可在设置中指定图像模型。
- 智能问答与仅资料库模式先识别图片主题，再按指定规范分组检索，保持可点击的文档引用；通用对话可直接分析图片。
- 后端支持图片上传、预览、清理、标准化问答接口和 SSE 流式图片输入；图片二进制独立保存，不放入会话 JSON。
- 支持 PNG、JPEG、GIF、WebP；每条消息最多 8 张，单张 8 MB，总计 24 MB。
- 请求失败时恢复问题和附件；上传未完成与回答生成期间避免重复发送。

使用：先配置模型接口及 API Key，再进入知识库问答，粘贴图片并发送。现有文档数据库、项目、会话和工具设置继续兼容。

验证：85 项自动化测试通过，并在 Windows 桌面窗口实际验证了粘贴截图、仅图片发送、原图预览、重新打开会话和图片追问。模型协议验证使用本地模拟服务，未调用用户的真实 DeepSeek API。
