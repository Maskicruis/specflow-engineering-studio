# SpecFlow Engineering Studio v0.5.1

> 修复正文引用跳转，并恢复被 MinerU 拆分的连续条文

## 本次修复

### 回答正文中的引用可以直接点击

- 正文不再只识别 `[1]`：现在兼容 `[片段3]`、`[片段 3]`、`[Segment 3]`、`【片段3】` 等模型常见输出。
- 所有兼容格式都会规范化为真正的 `[3]` 超链接，并与文后来源列表共用同一套 PDF 页码、条文、坐标和高亮逻辑。
- 提示词明确要求模型紧跟相关事实输出 `[1]`、`[2]`，减少引用集中到回答底部的情况。

### 连续条文不再以碎片参与回答

- 检索索引会按阅读顺序把 MinerU 拆开的相邻文本块重新组成完整语句。
- 支持中文词语恰好跨块的情况，例如 `相` + `邻区域` 会恢复成 `相邻区域`。
- 合并遇到完整句末或下一条文编号时停止，避免把 5.2.8 错接到 5.2.7。
- 原始 `document.json` 不会被改写；引用仍能定位原始 PDF，并会合并同页连续块的高亮范围。
- 已经入库的文档无需重新解析，安装新版本并重启后会自动按新规则建立检索索引。

## 稳定性与验证

- 自动化测试：48/48 通过。
- 新增正文多格式引用链接测试、连续条文拼接测试、下一条文边界测试和多块高亮区域测试。

## 安装说明

推荐下载 `SpecFlow-Engineering-Studio-Setup-0.5.1-x64.exe` 并覆盖安装。项目记录、Harness 会话、设置和文档数据库都会保留。也可使用 `SpecFlow-Engineering-Studio-Portable-0.5.1-x64.exe` 免安装运行。
