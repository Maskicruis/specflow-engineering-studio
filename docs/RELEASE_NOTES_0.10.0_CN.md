# SpecFlow Engineering Studio v0.10.0

## 实时问答

- 上游模型流式请求 → SSE 转发 → 前端实时 Markdown / 引用渲染。
- 独立显示思考增量（接口支持时），支持停止生成、超时、断线和不完整回答提示。
- 原非流式接口、图片输入、RAG、最近对话与引用定位继续兼容。

## Word 格式标准化

- 工具工作台新增「工程文档」类别与独立 Word 工具窗口，快捷键 `Ctrl+Alt+W`。
- 集成用户提供的 V35.1 VBA，原 BAS 文件逐字节保留并进行 SHA-256 校验。
- 支持仅 VBA，或 LLM 流式结构审查 → 用户审核 → VBA 排版。
- 文字建议单独授权，保留 Word 修订痕迹；不执行模型生成代码。
- 原件不覆盖；生成不含宏的 DOCX 与结构化报告。任务可恢复查看、取消。
- 新增标准化任务 / 进度 / 下载 API 和请求 Schema，方便外部 Agent 调用。

## 使用条件

Word 功能需要 Windows、Microsoft Word，以及「信任对 VBA 工程对象模型的访问」。SpecFlow 不替用户改变全局宏安全设置。PDF 解析仍需单独安装 MinerU；LLM 辅助审查需要配置模型并同意发送文档文本。

安装版和便携版保留现有配置、文档数据库和对话记录。升级前退出旧版；本机已有任务在新任务系统中独立保存。详细说明见 [Word 使用说明](WORD_FORMAT_CN.md)。
