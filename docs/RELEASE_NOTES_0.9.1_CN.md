# SpecFlow Engineering Studio v0.9.1

> 本次小版本修正道路纵向排水坡度的分段方向表达，确保箭头和动画严格按相邻节点运行。

## 道路排水坡度设计

- 每条坡段只允许连接两个相邻节点；旧数据中跨越中间节点的长连线会自动拆成多个独立坡段；
- 每个相邻坡段只显示一个方向箭头，移除重复的内部箭头，方向表达更清晰；
- 流动动画限定在当前坡段的起点与终点之间，不会跳过中间节点；
- 连续插入节点时自动逐段连线，也可框选两个节点后手动连接；
- 节点新增“设为分水高点”和“设为汇水低点”，可一次调整全部相邻坡段方向，支持中间高、两侧低等实际道路排水关系；
- 旧长连线拆分后要求分别填写各段真实距离，避免用示意画布长度代替工程长度。

## 兼容与验证

- 坡度设计数据架构升级至 v3，自动迁移旧版画布数据；
- 文档、索引、分组、对话、工程项目、模型设置与 Harness 集成保持兼容；
- 70 项自动化测试全部通过，并完成三节点分水高点的桌面界面验证。
