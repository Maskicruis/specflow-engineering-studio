第一次使用怎么做？

  1. 在下方选择 DOCX / DOC，程序只接收副本，不覆盖原件。
  2. 一般选「只统一格式」，勾选「允许执行随附 VBA」，再点击「开始统一格式」。无需模型或 API Key。
  3. 需要检查标题层级时，改选「先审查结构，再统一格式」。在主程序「设置 → 模型接口」配置模型，并另外同意发送文档文本。
  4. 模型模式先生成建议。逐项审核后点击「按审核结果统一格式」；不采用建议也可以运行全文排版。
  5. 处理完成后点击「下载标准化 DOCX」，在 Word 中核对编号、题注、目录与分页。文字建议默认不采用。
Word / VBA 环境如何准备？

需要 Windows 与 Microsoft Word。在 Word → 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置，勾选「信任对 VBA 工程对象模型的访问」，关闭 Word 设置对话框后点击「重新检测」。不需要启用所有宏；程序不会替您更改宏安全设置。WPS 或仅安装 Office 查看器不能代替 Microsoft Word。

V35.1 会处理正文、标题编号、图表题注、表格、图片、页眉及页面格式。它不是工程内容校审工具，最终文件仍需要人工核对。
