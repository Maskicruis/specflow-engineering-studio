# SpecFlow Engineering Studio v0.9.3

> 本次小版本将“工具工作台”重构为可扩展工具库，并把道路排水坡度设计迁移到独立桌面窗口。

## 独立工具窗口

- 道路排水坡度设计不再占用 SpecFlow 主页面，而是在独立原生窗口中运行；
- 重复点击同一内置工具时复用并聚焦现有窗口，避免产生多个相互冲突的画布；
- 主窗口关闭后，正在使用的工具窗口仍可继续工作，本地服务会保持运行；
- 坡度网络继续自动保存到本机，迁移窗口不会丢失已有节点、坡段或控制标高；
- 多功能计算器继续作为独立外部程序启动。

## 可扩展工具库

- 主页面只负责工具搜索、专业筛选、状态显示和启动；
- 工具注册表新增专业分类、图标、快捷键、启动方式和内部路由等标准字段；
- 内置窗口与外部程序采用统一启动入口，便于后续加入建筑、结构、给排水、电气等专业工具；
- 新增独立工具页面和资源路由，工具代码不再随主知识库页面加载；
- 保留 `Ctrl+Alt+C` 与 `Ctrl+Alt+R` 快捷键。

## 验证与兼容

- 78 项自动化测试全部通过，覆盖独立工具路由、桌面窗口桥接、注册表元数据和原有坡度网络计算；
- 已完成工具工作台和独立坡度窗口的应用内截图检查；
- 文档数据库、工程项目、问答记录、Harness 连接器和原有坡度设计数据保持兼容；
- 本次没有修改 Harness 插件协议，已安装的 0.9.2 连接组件无需重复更新。
